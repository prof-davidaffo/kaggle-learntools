# Notebook per Google Colab

File generati da `python ai_lab/tools/build.py`, da versionare insieme alle sorgenti. Non modificarli direttamente: modifica le traduzioni o il notebook Python sorgente e rigenera.

I link Colab aprono questi file dal branch configurato in `ai_lab/config.json` (`colab_ref`). La prima cella carica solo i file elencati in `runtime.json`, ne controlla gli hash e configura dataset, learntools e adattatore Keras. Gli originali Kaggle restano invariati.

I file devono essere inviati su GitHub prima che i link e il download automatico siano utilizzabili. La preparazione locale non equivale a una sessione Colab eseguita e verificata.
